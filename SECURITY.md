# Security and private data

This is a personal, local application. Do not expose its HTTP server to a public
network. Authentication cookies and OAuth tokens grant account access and must
remain private, even when passwords are not stored.

Never attach real course files, student records, browser profiles, `.env` contents,
calendar feed URLs, databases, or raw OAuth callbacks to a public issue. Use
fictional fixtures when reporting a bug. Review staged changes before publishing.

Report suspected vulnerabilities privately to the repository owner through an
available private GitHub contact channel. Do not publish working credentials or
exploit details in a public issue. No enterprise security guarantees are claimed.
